# 镜外生境 · Paint Beyond the Frame

让镜头里的真实，延伸成画外的一件小事。

上传一张照片，让云、浪、火花或枝叶跨入有留白的纸面，与彩色插画小人产生互动。摄影仍是主角；小人可以一个、两个或一小群，随照片选择，不固定双人模板。

[打开 ChatGPT Skill](https://chatgpt.com/skills?skill_id=6a75a66a78fc8191b62db93546bdabc0) · [查看精简 Skill](./paint-beyond-the-frame/SKILL.md)

## 线下快速体验

1. 选一张自己的风景、植物、街景或日常照片。
2. 在支持图片编辑的 AI 工具中上传原图，复制下面的提示词。
3. 看一个动作是否清楚、摄影是否仍然突出；只针对不满意的一点修改。

## 直接复制的提示词

```text
把这张照片延伸成摄影与插画融合的作品。保留原图比例、主体和摄影质感，不裁切、挤压或复制主体。让照片里的一个元素自然进入米白纸面，与彩色小人发生一件小事：枝条道路按原方向接续，水草云保留真实纹理成为摄影剪影，光斑落叶用少量散落元素连接。方向、人数和动作随照片选择，不固定两人。小人可进入真实照片、留在纸面或跨界协作，手脚与环境接触清楚，避开原有真实主体。小人用细线、两三块淡彩和少量阴影表现，高度先按整幅5%～7%尝试，动作清楚，光色来自原图；新增区域约一半或更多留白，只补必要道具和承托。避免硬切缝、满幅水彩、额外文字和签名。
```

也可以只说：

> 用镜外生境处理这张照片，彩色小人、自然融合、多留白。

在支持 Skill 的工具中，使用本仓库的 `paint-beyond-the-frame/` 目录；它仍需要可用的图片编辑能力。没有 Skill 功能时，也可以直接复制提示词体验。安装方式以所用工具的说明为准。

## 三个可选变化

- 单人发现：一个人接住一小块晚霞。
- 多人协作：几个人合力搬一朵云，各有动作。
- 安静续景：不加人物，只延续照片里的气氛。

优先让原来的东西继续发挥作用，例如踩涟漪、接火花、荡叶子秋千。需要时允许一次诗意变形，避免每张都变成长丝带。向下或向侧边扩展由元素运动和画面决定。

## 这次精简了什么

核心 Skill 从193行、16,996字符压缩后，目前为30行、1,511字符，按字符数减少约91%。规则保留自然连接、彩色人物、人数变化、照片保护、方向选择与留白；严格照片面板说明改为按需读取。每次生成的具体提示词以约150–300个中文字为目标，不复述整份规则。此次晚霞样图实际使用227个中文字，保留了彩色人物、自然连接和留白；随后又用机场光影和湖上晚霞原图测试了摄影纹理剪影与轻量彩色人物；画幅遵循仍有波动，其他素材需要继续体验。

## 保真边界

融合模式会允许局部边缘变化，AI编辑不能保证摄影区域逐像素不变；细小签名也可能丢失。请检查主体、取景和重要细节。

明确需要完整摄影矩形或像素校验时，参见[严格照片面板说明](./paint-beyond-the-frame/references/strict-photo-panel.md)。脚本只校验保护区域，不等于完整原图像素保真。
